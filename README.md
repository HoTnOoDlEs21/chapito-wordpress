# 🌐 Projeto WordPress – Chapitô

Este projeto foi desenvolvido com o objetivo de recriar o website oficial do [Chapitô](https://chapito.org/), utilizando o CMS WordPress. O foco foi replicar o design, estrutura e funcionalidades do site original, aplicando os conhecimentos adquiridos durante o curso de desenvolvimento web.

---

## 🚀 Tecnologias utilizadas

-   🧱 WordPress (instalação local)
-   🎨 Tema: [Sydney](https://wordpress.org/themes/sydney/)
-   🛠️ Personalizações feitas com:
    -   Elementor (page builder)
    -   Personalizador de temas do WordPress
    -   CSS adicional
-   📦 Backup com o plugin All-in-One WP Migration

---

---

## ♻️ Como restaurar o projeto

1. Instalar o WordPress localmente (ex: com AppServ, XAMPP ou LocalWP)
2. Instalar o plugin [All-in-One WP Migration](https://wordpress.org/plugins/all-in-one-wp-migration/)
3. Importar o ficheiro `.wpress`;
4. Ativar o tema **Sydney**
5. Corrigir os links caso necessário (ex: `siteurl` e `home` em `wp_options`)
